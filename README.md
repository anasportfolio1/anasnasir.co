# anasnasir.co

Personal site for Muhammad Anas, direct response email marketing for D2C ecommerce brands.

Static site, no build step. Open `index.html` to work on it locally.

## Files
- `index.html` — the main page
- `contact.html` — free audit request page (WhatsApp + email)
- `assets/images/` — portraits
- `assets/emails/` — email design work shown in The Work section
- `CNAME` — custom domain for GitHub Pages

## Deploying
Push to `main`. GitHub Pages serves the root of the branch.
